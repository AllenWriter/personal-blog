Clash は非常に強力なツールで、業界の主要なプロトコルのほとんどに対応しています。どんなプロトコルを試すにしても、**All in Clash** と言っていいでしょう。どのソフトをダウンロードすべきか悩む必要はありません。手元の設定を変換して Clash に渡すだけでいいのです。Clash はオープンソースで、Android、iOS、macOS、Linux などほぼすべてのプラットフォームに広がっています。

どの航空会社に乗るにしても、Clash はどんなチェックインの手続きでも手伝ってくれます。（しかも画面はもっと美しいです。）

## 豊富な機能

Clash には豊富な機能があります。たとえば次のとおりです。

- 複数のプロキシサーバーの設定と管理に対応しています。
- 複数のルールファイルのインポートと管理に対応しています。
- カスタムルールとポリシーの作成と適用に対応しています。
- HTTP プロキシのフィルタリングとリダイレクトに対応しています。
- DNS 解決の最適化と高速化に対応しています。
- ローカルネットワーク内でプロキシサーバーを共有することに対応しています。

Clash はターミナルのコマンドラインでも、GUI のユーザーインターフェースでも使えます。また、Windows、macOS、Linux、Android など、複数のプラットフォームで簡単に使えます。

## Clash サブスクリプション変換プラットフォームとは？

市場には二種類のサブスクリプションリンクがあります。一つは**ノードのサブスクリプションリンク**、もう一つは **Clash のサブスクリプションリンク**です。ノードのサブスクリプションリンクは、特定のプロトコルに対応したソフトウェアでしか認識されません。同様に、Clash が認識するのは **Clash のサブスクリプションリンク**だけです。

通常の**ノードのサブスクリプションリンク**は Clash でそのまま動かせないため、専用の Clash サブスクリプション変換プラットフォームが必要になります。ほとんどの**ノードのサブスクリプションリンク**は、**Clash のサブスクリプションリンク**に変換できます。世の中にはすでにたくさんの変換プラットフォームがありますが、データとサブスクリプション情報の安全を確保するためには、自分専用のプラットフォームを構築するのが最善です。詳しくは[《Clash サブスクリプション変換プラットフォームの構築》](/docs/clash-frontend-dashboard)をご覧ください。

## Clash のダウンロードと使い方は？

- [Windows チュートリアル](https://help.offshoreview.xyz/windows)
- [macOS チュートリアル](https://help.offshoreview.xyz/macos)
- [Android チュートリアル](https://help.offshoreview.xyz/android)

iOS には、Shadowrocket や Surge のように多くのプロトコルに対応したツールがすでにあるため、一般的に iOS では Clash を使いません。また、iOS 向けの Clash アプリも多くないので、そこまで苦労して使う必要はありません。

## すぐに Clash での変換を始めるには？

このサイトが運営している [Clash 変換サービス](https://clash.offshoreview.xyz/)を試すこともできます。ただし、情報漏えいを防ぐために、やはり自分で構築することをおすすめします。Vercel のフロントエンドと Docker のバックエンドのおかげで、構築のハードルはかなり下がりました。

## 変換後の「漏れた魚」とはどういう意味？

Clash はトラフィックを振り分けるツールです。海外のサイトは海外のトラフィックを使い、国内のトラフィックは国内の直接接続を使います。そのため、Clash は本質的に、主要な国内外のウェブサイトを記録したドメイン名リストのデータベースを内蔵して分類し、ブラウザーがアクセスするドメイン名を正規表現でマッチングして振り分けています。しかし、どうしてもこのデータベースに載っていないマイナーなサイトもあります。その名前のとおり、そうしたサイトを「漏れた魚」と呼びます。これらのマイナーなサイトを海外のトラフィックで通すか、国内で直接接続するかは、あなたが選べます。

私の意見では、「漏れた魚」には海外のノードを選ぶことをおすすめします。マイナーなサイトはたいてい海外で作られていますし、国内でちゃんとウェブサイトを作る人はほとんどいないからです。そうです、モバイルインターネットが席巻した今の 🇨🇳 には、マイナーなサイトが育つ土壌がありません。残っているものも、たいてい理想にこだわるプログラマーが作ったもので、海外のトラフィックを使えば問題なく開けます。
