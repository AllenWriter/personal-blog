要するに PowerShell のコマンドウィンドウを見た目よくするだけの話です。カレントディレクトリの言語環境、タグ、時刻などを表示することもできます（ちなみにこの記事は朝6時40分ごろに書いています）。ついでに言うと、Python がもう 3.9.5 まで出ていたのには驚きました。

## インストール

Microsoft Store で Windows Terminal を検索し、インストールをクリックします。

Win + R を押して `wt` と入力すると、Terminal が起動します。

または、フォルダの何もないところで右クリックし、`Open in Windows Terminal` を選びます。

ただし、初期設定では背景が真っ黒です。設定ファイルを開いて変更しましょう。

![image-20210527070628394](https://img.kuizuo.cn/image-20210527070628394.png)

profiles.list の下には、それぞれのターミナルが並んでいます。初期状態では、Windows PowerShell、Command Prompt、Azure Cloud Shell があります。

ここでは主に Windows PowerShell を最適化します。

### PowerShell の変更

以下は私の設定ファイルです。

```
{
"acrylicOpacity": 0.69999999999999996,
"commandline": "powershell.exe -nologo",
"fontFace": "JetBrainsMono NF",
"fontSize": 10,
"guid": "{61c54bbd-c2c6-5271-96e7-009a87ff44bf}",
"hidden": false,
"name": "Windows PowerShell",
"useAcrylic": true
},
```

- useAcrylic: `true` すりガラス効果です。背景に画像を使う場合は、すりガラスは使わないほうがよいです。
- acrylicOpacity: `0.7` 透明度です。
- fontFace: `JetBrainsMono NF` フォントです。ここでは JetBrains のフォントを使っています。強くおすすめします。
- fontSize: `10` フォントサイズです。

[フォントのダウンロード](https://github.com/ryanoasis/nerd-fonts/tree/master/patched-fonts)。ただし、ダウンロードには海外サイトへの接続環境（VPN など）が必要と思われます。Windows 用の .ttf をダウンロードして、ダブルクリックでインストールします。

### モジュールのダウンロード

**管理者**として PowerShell を開き、次のコマンドを入力します。

グループの権限を設定しておかないと、必要なモジュールをインストールできません。

```shell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
```

`oh-my-posh` と `posh-git` のダウンロードにも、おそらく VPN が必要です。そうしないと、ダウンロードできない可能性が高いです。

```shell
Install-Module oh-my-posh -Scope CurrentUser
Install-Module posh-git -Scope CurrentUser
Install-Module Get-ChildItemColor -Scope CurrentUser
```

確認が出たら、はい（Y）または すべて（A）を選択します。

### テーマのインストール

ダウンロードが終わったら、次のコマンドを入力してテーマをプレビューします。

```shell
Get-PoshThemes
```

![image-20210527071827101](https://img.kuizuo.cn/image-20210527071827101.png)

上のテーマの中には、目立たないウォーターマークのような文字が混ざっているものもあるようです。

一時的にテーマを切り替えるには、次のコマンドを使います。

```shell
Set-PoshPrompt jandedobbeleer
```

今の私の設定に少し似ています（当時、jandedobbeleer のテーマをベースに改造したからです）。ただし、これは一時的なテーマです。テーマファイルを変更する必要があり、パスは一般的に `C:\Users\用户名\Documents\WindowsPowerShell\Microsoft.PowerShell_profile.ps1` です。

または、次のコマンドを入力して開きます。

```
$profile
if (!(Test-Path -Path $PROFILE )) { New-Item -Type File -Path $PROFILE -Force }
notepad $PROFILE
```

以下のコードを追加して保存し、Terminal を再起動すれば有効になります。

```shell
Import-Module Get-ChildItemColor
$env:PYTHONIOENCODING="utf-8"
Import-Module posh-git
Import-Module oh-my-posh

$DefaultUser = 'kuizuo'
# Set theme
Set-PoshPrompt jandedobbeleer
Set-PSReadlineKeyHandler -Key Tab -Function MenuComplete
```

`themes` ディレクトリに `xxxx.omp.json` という新しいファイルを作成します。例えば `kuizuo.omp.json` です。

### Git Bash の追加

ここでの `E:/Git` は私の Git のインストール先です。ご自身の環境に合わせて変更してください。

```json
{
  "hidden": false,
  "name": "Git Bash",
  "commandline": "E:/Git/bin/bash.exe -li",
  "icon": "E:/Git/mingw64/share/git/git-for-windows.ico",
  "startingDirectory": "%USERPROFILE%"
}
```
