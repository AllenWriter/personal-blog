## How it works

All three apps were built in Dify. The core of it is Dify's video generation plugin.

If you don't know Dify yet, think of it as a playground for AI apps, where you assemble an app like playing with building blocks. Official site: [https://dify.ai/](https://dify.ai/)

![Dify homepage and workflow preview](/docs/dify-video-plugin/dify-homepage.png)

Here are the full steps to reproduce it. It takes about three minutes.

### 1. Sign up and log in to Dify

Open [https://cloud.dify.ai/](https://cloud.dify.ai/) and sign up with your email. You can switch the language in the top-right corner. You can also install the open-source community edition.

![Switching the language in the top-right corner of cloud.dify.ai](/docs/dify-video-plugin/register-language-switch.png)

### 2. Install the video plugin and complete authorization

Dify itself is not a video model. Video generation relies on an external plugin.

Top-right: "Plugins" → "Explore Marketplace". Search for "video" and find **Doubao Image and Video Generator**. Its capabilities are based on Doubao.

![Searching "video" in the Marketplace and finding Doubao Image and Video Generator](/docs/dify-video-plugin/marketplace-search-video.png)

After installing, enter your own API key to complete authorization. Don't write the key into the docs or commit it to a repository.

![Plugin authorization panel: enter your Volcengine API key](/docs/dify-video-plugin/plugin-authorization.png)

### 3. Create an app

After you've signed up for the platform, you still need to create an app and then add video generation to it.

#### 3.1 Copy a ready-made app

Under the hood, a Dify app is a DSL. On the web, use "Import DSL file" and paste in a link:

![Import DSL file dialog](/docs/dify-video-plugin/import-dsl-dialog.png)

- Text-to-video: [https://r2.xmsex.net/2025/06/07cd66a9979953c29475dd34dd8663bf.yml](https://r2.xmsex.net/2025/06/07cd66a9979953c29475dd34dd8663bf.yml)
- All-in-one image-to-video: [https://r2.xmsex.net/2025/06/3334f9aed0fd9dbe00b1872bf931184c.yml](https://r2.xmsex.net/2025/06/3334f9aed0fd9dbe00b1872bf931184c.yml)
- Image-to-video: [https://r2.xmsex.net/2025/06/6b76198e75d363debeb065bc74f1160d.yml](https://r2.xmsex.net/2025/06/6b76198e75d363debeb065bc74f1160d.yml)

Once the import succeeds, you should see the app interface below:

![App interface after a successful import](/docs/dify-video-plugin/imported-app-ui.png)

#### 3.2 Build from scratch

Create a blank app, choose Chatflow, and fill in a name and description.

![Creating a blank Chatflow app](/docs/dify-video-plugin/create-chatflow.png)

Add a tool node and choose Doubao Generator. Depending on the effect you want, pick text-to-image, text-to-video or image-to-video.

![Adding a tool node and selecting Doubao Generator](/docs/dify-video-plugin/add-doubao-tool.png)

Each tool node has default inputs and outputs. For text-to-video, the input is the prompt and the output is the video the plugin generates.

![Input and output parameters of the text-to-video tool node](/docs/dify-video-plugin/tool-io-params.png)

I connect the input to the output of the previous LLM step. A user's prompt is often not detailed enough, so first let the model expand it into a detailed video prompt, then send it to the generation node.

![Connecting the LLM-expanded prompt to the video generation node](/docs/dify-video-plugin/llm-prompt-expand.png)

This plugin can also be used inside an Agent node.

![Using the video plugin in an Agent node](/docs/dify-video-plugin/agent-node-usage.png)

If you don't understand workflows yet, start here: [Dify Workflow](https://docs.dify.ai/zh-hans/guides/workflow/readme).

## Summary

In the past, generating video in Dify usually meant using an HTTP node to call an external API. It works, but it isn't elegant, and everyone who wants to make videos has to set it up again. This is a common need, so it's better to make it a plugin where you just enter an API key and go.
