重要な情報を強調するときは、自分で枠線を描くのではなく、提示ブロックを使ってください。3つの書き方はどれも同じ見た目になります。

## 推奨される書き方

コードフェンスの言語に、種類の名前を書きます。

```tip
これはヒントです。次のステップ、近道、または「実はもっと簡単にできる」といった内容に向いています。
```

```info
一般的な情報です。主な流れを中断せずに、背景を補足します。
```

```warning
注意すべき制限、互換性の問題、または踏みやすい落とし穴です。
```

```danger
事故につながりかねない操作です。データベースの削除、設定の上書き、元に戻せない手順など。
```

```success
正しく完了しました。次のステップに進めます。
```

## 引用を使うこともできます

GitHub の警告構文：

> [!NOTE]
> ```note と同じく、提示ブロックにまとめられます。

または、以前の Docusaurus の書き方で、1行目に種類の名前を書きます。

> **tip**
> これはヒントのブロックです。

## コードブロックそのもの

通常のコードは、上部のバーとコピーボタン付きのフェンスのままです。

```ts
export const n = 1
```
