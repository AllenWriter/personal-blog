Really, this is just about making the PowerShell window look nicer. It can also show the language environment of the current directory, tags, the time (yes, this is an article I wrote around 6:40 in the morning), and so on. (Side note: I didn't expect Python to already be at 3.9.5.)

## Installation

Search for Windows Terminal in the Microsoft Store and click install.

Press win + R and type `wt` to launch Terminal.

Or right-click an empty area in a folder and choose `Open in Windows Terminal`.

By default, though, the background is pure black. To change it, open the configuration file.

![image-20210527070628394](https://img.kuizuo.cn/image-20210527070628394.png)

Under profiles.list are the different terminals. By default there's Windows PowerShell, Command Prompt, and Azure Cloud Shell.

I'm mainly optimizing Windows PowerShell here.

### Changing PowerShell

Here's my configuration file

```
{
"acrylicOpacity": 0.69999999999999996,
"commandline": "powershell.exe -nologo",
"fontFace": "JetBrainsMono NF",
"fontSize": 10,
"guid": "{61c54bbd-c2c6-5271-96e7-009a87ff44bf}",
"hidden": false,
"name": "Windows PowerShell",
"useAcrylic": true
},
```

- useAcrylic: `true` frosted glass effect. If you're using a background image, don't use the frosted glass effect.
- acrylicOpacity: `0.7` transparency
- fontFace: `JetBrainsMono NF` font. I'm using JetBrains' font here, and I strongly recommend it.
- fontSize: `10` font size

[Font download](https://github.com/ryanoasis/nerd-fonts/tree/master/patched-fonts). You'll probably need a VPN to download it, though. Download the Windows .ttf file and double-click it to install.

### Installing modules

Open PowerShell as **administrator** and enter the following command.

This sets the group permissions; without it, the required modules can't be installed.

```shell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
```

To download `oh-my-posh` and `posh-git`, you'll probably also need a VPN, otherwise the download will most likely fail.

```shell
Install-Module oh-my-posh -Scope CurrentUser
Install-Module posh-git -Scope CurrentUser
Install-Module Get-ChildItemColor -Scope CurrentUser
```

When prompted, choose Yes (Y) or Yes to All (A).

### Installing a theme

After the download finishes, enter the command below to preview the themes.

```shell
Get-PoshThemes
```

![image-20210527071827101](https://img.kuizuo.cn/image-20210527071827101.png)

Looks like some of the themes above have a barely visible watermark in them.

To temporarily switch to a theme

```shell
Set-PoshPrompt jandedobbeleer
```

It looks a little like mine now (because I based mine on the jandedobbeleer theme). But this is only a temporary theme. To make it permanent, you need to edit the profile file, usually located at `C:\Users\用户名\Documents\WindowsPowerShell\Microsoft.PowerShell_profile.ps1`

Or enter the commands below to open it

```
$profile
if (!(Test-Path -Path $PROFILE )) { New-Item -Type File -Path $PROFILE -Force }
notepad $PROFILE
```

Add the code below, save, and restart Terminal to apply it.

```shell
Import-Module Get-ChildItemColor
$env:PYTHONIOENCODING="utf-8"
Import-Module posh-git
Import-Module oh-my-posh

$DefaultUser = 'kuizuo'
# Set theme
Set-PoshPrompt jandedobbeleer
Set-PSReadlineKeyHandler -Key Tab -Function MenuComplete
```

### Modifying the theme

The official preset themes didn't satisfy me, so I went to read the official documentation: [Introduction | Oh my Posh](https://ohmyposh.dev/docs/)

First, the official themes live in this path: `C:\Users\用户名\Documents\WindowsPowerShell\Modules\oh-my-posh\3.144.0\themes`

Create a new file named `xxxx.omp.json` in the `themes` directory, for example `kuizuo.omp.json`.

### Adding Git Bash

The `E:/Git` here is my Git installation path. Change it to match yours.

```json
{
  "hidden": false,
  "name": "Git Bash",
  "commandline": "E:/Git/bin/bash.exe -li",
  "icon": "E:/Git/mingw64/share/git/git-for-windows.ico",
  "startingDirectory": "%USERPROFILE%"
}
```
