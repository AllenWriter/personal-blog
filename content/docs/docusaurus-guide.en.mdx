## [What is Docusaurus (the Document Dragon) 🦖?](#what-is-docusaurus)

Docusaurus is an open-source static site generator, led by Facebook and built on the React framework. It makes it easy to build modern, responsive static websites. In the official slogan's words, it is for "quickly building content-centric websites."

Docusaurus is a compound word made of Document + Dinosaurs, so it can be translated literally as "Document Dragon" (compound words like this are really hard to pronounce). It's an American pun, a bit like a parody of a well-known comedy troupe's name.

- Docusaurus [GitHub repository](https://github.com/facebook/docusaurus)
- [Official docs](https://docusaurus.io/zh-CN/)

## [What can Docusaurus do?](#what-docusaurus-can-do)

- Provides documentation features such as versioning, search, and syntax highlighting.
- Supports a blog feature, so you can quickly set up a blog.
- Theme system: customize the look of your theme. See [case studies](https://docusaurus.io/zh-CN/showcase).
- Plugin system: extend with plugins.
- Built-in SEO support, so search engines can crawl it easily.
- Works out of the box with simple configuration.
- An active community, open-sourced by Facebook.
- Multilingual support, so you can build a globally accessible site.

> **info**
> If your product is building a help documentation center for users around the world, then the Document Dragon should be your only choice.
