Are you still struggling to figure out what tech stack a website you admire is built with? If so, this Chrome extension is worth having.

## Preface

As front-end developers, the browser is basically our habitat. With the rise of the modern front-end ecosystem, countless tech stacks have appeared, and all kinds of websites have sprung up. When you face a familiar yet unfamiliar website and want to know what it's built with, you normally have to go through developer tools or dig into the JS. But there is a Chrome extension that can easily analyze the technologies used by a given website.

## Getting Started

As the title says, it can roughly analyze which programming languages, frameworks, libraries, web servers and so on a website uses.

Here are the official link and some screenshots of it in use.

I've tested it on several websites, and the analysis results matched what's actually there, as the screenshots show. In principle it shouldn't misidentify things; at worst it fails to detect something. Still, the effect is very noticeable. When you come across a website you admire, having it analyze and explain the tech stack for you is about the best thing you could ask for.
