No matter which flight you're on, Clash can help you complete any boarding procedure. (And the interface is even nicer.)

## Rich Features

Clash offers a rich set of features, such as:

- Support for configuring and managing multiple proxy servers.
- Support for importing and managing multiple rule files.
- Support for writing and applying custom rules and policies.
- Support for filtering and redirecting HTTP proxies.
- Support for optimizing and accelerating DNS resolution.
- Support for sharing a proxy server on the local network.

Clash can be used both in a terminal command line and in a GUI user interface. It also runs easily on many platforms, including Windows, macOS, Linux and Android.

## What Is a Clash Subscription Conversion Platform?

There are two kinds of subscription links on the market: the **node subscription link** and the **Clash subscription link**. A node subscription link can only be recognized by software that is compatible with a specific protocol. Likewise, Clash only accepts **Clash subscription links**.

A regular **node subscription link** can't run directly in Clash, so you need a dedicated Clash subscription conversion platform to do the job. Most **node subscription links** can be converted into **Clash subscription links**. ## What Does the "Fish That Slipped Through the Net" Mean After Conversion?

Clash is a traffic-splitting tool: foreign websites use foreign traffic, and domestic traffic goes through the local connection. So Clash essentially sorts traffic by building in a domain-name list database that records mainstream domestic and foreign websites, and it uses regular expressions to match the domain names your browser visits in order to split the traffic. However, some niche websites will never be in that database. As the name suggests, such sites are "fish that slipped through the net." You can choose whether these niche websites go through foreign traffic or connect directly locally.
